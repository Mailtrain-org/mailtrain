# Reporting a security issue

Please [report vulnerabilities privately through GitHub](https://github.com/Mailtrain-org/mailtrain/security/advisories/new). Include the affected version, the impact and enough detail for us to investigate. Use a test installation you control and keep reports free of real credentials and subscriber data.

If the private reporting form is unavailable, open a GitHub issue asking a maintainer how to reach them privately. Keep vulnerability details out of the issue.
